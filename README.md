# JavaScript Problem Solving

This repository contains solutions to five JavaScript problem-solving challenges. Tt focuses on practicing JavaScript fundamentals, logical thinking, functions, arrays, objects, loops, conditionals, and input validation.

## Problems

1. **Problem 1- Match Winner**
   - Determines the result of a football match based on the goals scored by two teams.

2. **Problem 2- Elevator Weight Safety Checker**
   - Calculates the total weight of passengers and checks whether the elevator is within its safe weight limit.

3. **Problem 3- AI Token Cost Calculator**
   - Calculates the cost of AI token usage after the free token limit.

4. **Problem 4- Top Rated Restaurant Finder**
   - Finds the restaurant with the highest rating and returns its name in uppercase.

5. **Problem 5- API Response Time Monitor**
   - Calculates the average API response time while handling invalid input.

## Concepts Practiced

- JavaScript Functions
- Conditional Statements
- Arrays and Objects

- `typeof` and `Array.isArray()`
- Input Validation
